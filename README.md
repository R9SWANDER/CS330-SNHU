# CS330-SNHU

The project in this class was to modify an already functional system by added shapes and textures to the scene, and also by integrating entirely new fucntions to the application to enable the completeion of the final project. This course has taught me alot about modifying pre-written code faithfully. In all previous courses, I have made all the code myself and therefore had the priveledge of knowing all the functions of all the methods in the system, and therefore exactly what to do to gain any given output. However, this class was different becuase it was created on the basis of a provided system, with both the provided system and the code built on top of it I knew little about. It was very interesting to learn how the application communicated with the underlying provided system, and how I could use already coded functionality to assist in adding new functionality to the program. I could definitely apply this new knowledge to any future project I work on, where I will not be creating new code from the ground up, which will likely be most projects.

Throughout this project I learned how to troubleshoot code and programs without understanding the underlying system completely, which in my eyes seems to be troubleshooting through abstraction. I also learned how to analyze provided code better. I developed and used these skills throughout the project milestones to better understand and implement new functionality to the program. In the future I will definitly incorporate analyzing the code structure of the program I'm working on before begining to develop onto it, to better make my implementations match the provided code structure. I also used iteration quite alot throughout the course, trail and error helped me better understand how different values of variables would effect the output of the program.

This class has taught me alot about both the visual modeling world and the programming world, and most improtantly how they intersect. Everything I've learned in this course will be useful in future projects where I work on provided code, or in the workfroce when I likely will use provided frameworks to build new applications. Furthermore, the modeling aspect of this course has given me immense knowledge of basic modeling techniques, which would likely be useful in professional fields like game development, or even just creation of animations.
